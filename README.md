# Portfolio-Website
A centralized hub to showcase my projects, skills, and progress. This space documents my journey in development. Building functional tools, solving logic, and turning ideas into clean, efficient code.

### Key Features
* Responsive Design: Fully optimized for all screen sizes—from massive monitors to mobile devices—using CSS Flexbox and Grid.
* Interactive Project Cards: Custom "Touch-to-Reveal" logic for mobile, ensuring a clean aesthetic without losing functionality.
* Modern Navbar: A blurred-glass (glassmorphism) header with a custom-coded mobile hamburger menu and slide-out navigation.
* Skill-Tag Carousel: A horizontal-scroll skill section for experience items, maximizing mobile screen real estate.
* Vertical Timeline: A professional professional experience layout with a custom-styled vertical connector and status indicators.

### Built With
* HTML5 - Semantic structure for accessibility and SEO.
* CSS3 - Custom properties, Media Queries, and advanced animations.
* JavaScript (ES6+) - State management for UI components and event bubbling handling.

### Mobile Preview
The site adapts dynamically:
* Hero Section: Typography scales for perfect readability.
* Expertise: Cards transition from a horizontal row to a vertical stack.
* Experience: Skill tags become swipeable carousels.
